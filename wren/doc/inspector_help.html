Wren Inspector

Встроенный отладчик и REPL для Qt/D приложений

Wren Inspector — окно, встроенное в ваше приложение, которое позволяет в режиме реального времени исследовать Qt-виджеты, читать произвольную память, запускать Wren-скрипты и просматривать логи из D-кода — без остановки приложения.

ПанельНазначениеМетоды записи
Monitor (левая) Лог из D-кода. Пассивный поток. Кнопка Clear. Log.print / info / ok / warn / error / val / sep
Console (правая) Вывод REPL и сценариев. Активный поток. Out.print / info / ok / warn / error / val / sep
Input (нижняя) Многострочный редактор Wren-кода. Ctrl+Enter = Run, Ctrl+↑↓ = история

Быстрый старт

Подключение в D-программе

import wren_vm;
import wren_console;

// В main():
LoadWren("./dll/wren_bridge.dll");
LoadQt("./dll");
auto app = new QApplication("myapp");

auto vm  = new WrenVM(&wWrite, &wError);
auto ins = createInspector(vm, cast(void*)null, "./wren/scenarios");
ins.show();

// Зарегистрировать переменные для просмотра из Wren:
WrenVM.registerPointer("myVar", cast(void*)&myVar);

app.exec();

Первые команды в REPL

// Показать все виджеты:
Inspector.allWidgets.each {|w| Out.print(w) }

// Найти виджет по имени:
var w = Inspector.find("myButton")
Out.print(w.className)    // QPushButton

// Дамп свойств:
w.dump

// Прочитать байт по адресу переменной:
var a = Inspector.namedPtr("myVar")
Out.print(Inspector.readI32(a))

Контекст выполнения

Каждое нажатие Run создаёт новый изолированный модуль (console_1, console_2, …). Переменные, объявленные в одном запуске, не видны в следующем.

⚠ var x = 5 в одном запуске — потеряно после нажатия Run снова.

Для сохранения состояния между запусками используйте:

СпособПример
Named pointers (C++ map) Inspector.namedPtr("x") → Inspector.readI32(addr)
Qt-свойства виджета w.setProperty("myKey","42") → w.property("myKey")
Сценарии (.wren файлы) Загружаются через кнопку Load, весь файл в одном модуле

PREAMBLE — автоматические импорты

В каждый запуск REPL автоматически добавляется:

import "log"       for Log
import "out"       for Out
import "check"     for Check
import "inspector" for Inspector, QtObj

Не нужно писать import вручную в REPL. В сценариях — нужно.

Класс Inspector

Все методы статические. Содержит поиск виджетов, чтение памяти и реестр именованных указателей.

Поиск виджетов

СигнатураВозвратОписание
Inspector.find(name) QtObj Найти виджет по objectName. Если не найден — isNull == true.
Inspector.allWidgets List[QtObj] Все виджеты приложения (QApplication::allWidgets()).
Inspector.topWidgets List[QtObj] Виджеты верхнего уровня (topLevelWidgets()).
Inspector.findByClass(cls) List[QtObj] Все виджеты указанного класса. cls — строка, напр. "QPushButton".
Inspector.atAddress(n) QtObj Создать QtObj из числового адреса. Не проверяет валидность. 
// Найти все кнопки и показать их тексты
var btns = Inspector.findByClass("QPushButton")
Out.print("Buttons: %(btns.count)")
btns.each {|b|
    Out.print("  %(b.name)  text=%(b.property("text"))")
}

// Round-trip через адрес
var w  = Inspector.find("mainWindow")
var w2 = Inspector.atAddress(w.address)
Out.print(w2.name)   // mainWindow

Чтение памяти

Все адреса — числа (Num). Адрес 0 возвращает 0 без краша.
СигнатураТип C++РазмерДиапазон
Inspector.readU8(addr) uint8_t 1 байт0…255
Inspector.readU16(addr) uint16_t 2 байта0…65535
Inspector.readU32(addr) uint32_t 4 байта0…4 294 967 295
Inspector.readU64(addr) uint64_t 8 байтдо 2⁵³ точно*
Inspector.readI8(addr) int8_t 1 байт−128…127
Inspector.readI16(addr) int16_t 2 байта−32768…32767
Inspector.readI32(addr) int32_t 4 байта±2 147 483 647
Inspector.readI64(addr) int64_t 8 байтдо 2⁵³ точно*
Inspector.readF32(addr) float 4 байтаIEEE 754 float
Inspector.readF64(addr) double 8 байтIEEE 754 double
Inspector.readPtr(addr) uintptr_t4/8 байтадрес (uintptr)
Inspector.deref(addr) ——readPtr → QtObj
Inspector.hexDump(addr, n)—n байтвывод в Console
Inspector.hexDump(addr) —128 байтвывод в Console

* Wren хранит числа как double (53-бит мантисса). int64 > 2⁵³ теряет точность.

// Прочитать 4 байта по адресу переменной
var a = Inspector.namedPtr("myInt")
Out.print(Inspector.readI32(a))

// Прочитать float
var af = Inspector.namedPtr("myFloat")
Out.print(Inspector.readF32(af))

// Hex dump 32 байт по адресу
var addr = Inspector.find("mainWin").address
Inspector.hexDump(addr, 32)

// vtable pointer объекта
var vtbl = Inspector.readPtr(addr)
Out.print("vtable @ 0x%(vtbl)")

Именованные указатели (Named Pointers)

Регистрируйте из D любые переменные/структуры, чтобы получить к ним доступ из Wren по имени.

СигнатураОписание
Inspector.namedPtr(name)Адрес (Num) зарегистрированного указателя. 0 если не найден.
Inspector.namedQtObj(name)QtObj по имени (если указатель — это QObject*).
Inspector.pointerNamesList[String] — все зарегистрированные имена.

Регистрация из D:

WrenVM.registerPointer("myStruct", cast(void*)&myStruct);
WrenVM.registerPointer("counter",  cast(void*)&counter);
WrenVM.registerPointer("mainWin",  mainWin.getWH());   // QWidget*

WrenVM.unregisterPointer("counter");
WrenVM.clearPointers();  // удалить все

Использование из Wren:

// Список зарегистрированных имён
Out.print(Inspector.pointerNames)

// Прочитать int по имени
var a = Inspector.namedPtr("counter")
Out.print(Inspector.readI32(a))

// Получить Qt-виджет по имени
var w = Inspector.namedQtObj("mainWin")
w.dump

Класс QtObj

Обёртка над QObject*. Создаётся через Inspector.find(), Inspector.atAddress() и т.п.

⚠ QtObj не проверяет валидность указателя. Если объект удалён Qt — обращение к нему вызовет краш.

Базовые свойства

Метод / ГеттерТипОписание
w.name StringobjectName()
w.className StringИмя C++ класса: "QPushButton", "QLabel", …
w.address Num Числовой адрес объекта (uintptr_t).
w.isNull Bool true если указатель == null.
w.toString String"ClassName(objectName)"
w.property(key)StringЗначение Qt-свойства. Ключ — строка ("visible", "text", …).
w.setProperty(key, val)BoolУстановить Qt-свойство. val — строка.
w.invoke(method)BoolВызвать слот без аргументов ("show", "hide", "update").

w.methods List[String]Все мета-методы (сигналы + слоты + методы).
w.signals List[String]Только сигналы.

var w = Inspector.find("saveBtn")
Out.print(w.className)           // QPushButton
Out.print(w.property("text"))   // Save
Out.print(w.property("enabled")) // true
w.setProperty("text", "Saved!")  // изменить текст
w.invoke("hide")                 // скрыть

// Вывести все сигналы кнопки
w.signals.each {|s| Out.print("  signal: %(s)") }

Дерево объектов

МетодТипОписание
w.parent QtObjРодительский объект. isNull для top-level.
w.childCount Num Количество дочерних объектов.
w.childAt(n) QtObjДочерний объект по индексу.
w.children List[QtObj]Все дочерние объекты.
// Рекурсивный обход дерева виджетов
var indent = ""

var printTree = Fn.new {|w, depth|
    var pad = "  " * depth
    Out.print("%(pad)%(w.className)(%(w.name))")
    var i = 0
    while (i < w.childCount) {
        // Wren не поддерживает рекурсию через Fn — разворачиваем вручную
        var c = w.childAt(i)
        Out.print("%(pad)  %(c.className)(%(c.name))")
        i = i + 1
    }
}

Inspector.topWidgets.each {|w| printTree.call(w, 0) }

МетодОписание

Интеграция с D — registerPointer

Самый простой способ передать данные из D в Wren Inspector.

import wren_vm;

// Примитивы
int    counter = 0;
float  price   = 3.14f;
double total   = 100.0;
WrenVM.registerPointer("counter", cast(void*)&counter);
WrenVM.registerPointer("price",   cast(void*)&price);
WrenVM.registerPointer("total",   cast(void*)&total);

// C-строка
const char* msg = "Hello";
WrenVM.registerPointer("msg",     cast(void*)msg);
WrenVM.registerPointer("msg_ptr", cast(void*)&msg);

// Структура
struct Node { int value; float weight; Node* next; }
Node root = {42, 1.5f, null};
WrenVM.registerPointer("root", cast(void*)&root);

// Qt-виджет
WrenVM.registerPointer("mainWin", mainWin.getWH());

Интеграция с D — вызов Wren из D

import std.conv : to;

// Передать адрес переменной прямо в код
int x = 777;
size_t addr = cast(size_t)&x;
vm.interpret("dbg",
    "Out.print(Inspector.readI32(" ~ to!string(addr) ~ "))");

// Вызвать сценарий программно
vm.loadFile("./wren/scenarios/my_check.wren", "check_run");

// Утилита для вывода любого адреса
void inspectAt(T)(ref T var, int bytes = T.sizeof * 4) {
    size_t a = cast(size_t)(&var);
    vm.interpret("insp_" ~ to!string(a),
        "Inspector.hexDump(" ~ to!string(a) ~ "," ~ to!string(bytes) ~ ")");
}

Логирование из D в Monitor

// Импортировать Log один раз в модуле "main":
vm.interpret("main", `import "log" for Log`);

// Затем использовать:
vm.interpret("main", `Log.ok("File saved")`);
vm.interpret("main", `Log.val("rows", " ~ to!string(rows) ~ `")`);
vm.interpret("main", `Log.sep("─────")`);

// Обёртка для удобства:
void logOk(string msg) {
    vm.interpret("main", `Log.ok("` ~ msg ~ `")`);
}
void logVal(string label, string val) {
    vm.interpret("main", `Log.val("` ~ label ~ `","` ~ val ~ `")`);
}

Пример: обход связанного списка

Структура в D:

struct Node {
    int   value;   // offset 0, 4 bytes
    float weight;  // offset 4, 4 bytes
    Node* next;    // offset 8, 4 bytes (32-bit)
}
Node* head = ...;
WrenVM.registerPointer("head", cast(void*)head);

Скрипт Wren:

var VALUE  = 0   // offset int value
var WEIGHT = 4   // offset float weight
var NEXT   = 8   // offset Node* next

var ptr = Inspector.namedPtr("head")
var i   = 0

Out.sep("Linked list")
while (ptr != 0) {
    var val = Inspector.readI32(ptr + VALUE)
    var w   = Inspector.readF32(ptr + WEIGHT)
    Out.print("[%(i)]  @0x%(ptr)  value=%(val)  weight=%(w)")
    ptr = Inspector.readPtr(ptr + NEXT)
    i = i + 1
    if (i > 10000) { Out.warn("Limit exceeded — possible cycle!"); break }
}
Out.ok("Total nodes: %(i)")

Пример: просмотр структуры

Структура в D:

struct PlayerState {

Out.val("maxHp", Inspector.readI32(a +  4))
Out.val("x",     Inspector.readF32(a +  8))

// Первые байты строки

Пример: hex dump и анализ

// Дамп любого виджета
var w = Inspector.find("myWidget")
w.hexDump(128)

// Дамп по числовому адресу
Inspector.hexDump(Inspector.namedPtr("buffer"), 256)

// Программный анализ hex dump
var rows = w.hexDumpStr(64).split("\n")
Out.print("Rows: %(rows.count)")    // 4
Out.print(rows[0])                 // "0000  xx xx ..."

// Найти ненулевые байты в первых 16
var a = Inspector.namedPtr("buffer")
var i = 0
while (i < 16) {
    var b = Inspector.readU8(a + i)
    if (b != 0) Out.print("[%(i)] = %(b)")
    i = i + 1
}

Пример: поиск и инспекция виджетов

// Найти все QLabel и показать их тексты
Inspector.findByClass("QLabel").each {|lbl|
    var txt = lbl.property("text")
    Out.print("%(lbl.name): %(txt)")
}

// Дерево от корневого окна
var top = Inspector.topWidgets[0]
var depth = 0
var stack = [top]
while (stack.count > 0) {
    var w   = stack[0]
    stack.removeAt(0)
    Out.print("%(w.className)(%(w.name))")
    w.children.each {|c| stack.add(c) }
}

// Посчитать виджеты по классам
var classes = ["QPushButton", "QLabel", "QLineEdit", "QComboBox"]
classes.each {|cls|
    var n = Inspector.findByClass(cls).count
    Out.val(cls, n)
}

Пример: тестирование GUI (Check)

Check.reset()
Out.sep("UI sanity checks")

// Виджеты существуют

// Минимальное количество виджетов

Check.report()

Сценарии — файлы .wren

Сценарии — это .wren-файлы в директории wren/scenarios/. Загружаются через выпадающий список Scenario + кнопку Load. Каждая загрузка создаёт уникальный модуль.

В сценариях необходимо явно писать import — PREAMBLE не добавляется автоматически.

Шаблон сценария

// wren/scenarios/my_scenario.wren
import "out"       for Out
import "log"       for Log
import "check"     for Check
import "inspector" for Inspector, QtObj

Out.sep("My Scenario")
// ... ваш код ...
Out.ok("Done")

ФайлОписание

check_inspector.wren Самотестирование API Inspector через Check.*.
find_and_inspect.wren Найти виджет по имени, показать все свойства.
count_by_class.wren Статистика: сколько виджетов каждого класса.

Создание нового сценария

  1. Создайте файл wren/scenarios/my_name.wren
  2. Добавьте импорты в начало
  3. Перезапустите приложение (или перезагрузите список)
  4. Выберите из выпадающего списка → Load
