# vbaformat — форматтер VBA-кода (CLI)

Автономная утилита на чистом D (стандартная библиотека, зависимостей нет).
Восстанавливает отступы в текстовых файлах с VBA/VB6-кодом (.bas, .cls, .frm,
экспортированные из VBE модули MS Access).

## Сборка

```bat
build.bat        rem dmd -O -release -inline -> vbaformat.exe
```

## Использование

```
vbaformat <файл> [опции]

  -o, --output <файл>  файл результата (по умолчанию — stdout)
      --in-place       перезаписать исходный файл
      --tabs           отступ табуляцией вместо пробелов
      --indent=N       число пробелов в отступе (по умолчанию 4)
      --blank-lines=N  максимум подряд идущих пустых строк (по умолчанию 2)
      --check          ничего не писать; код возврата 1, если файл не отформатирован
```

Примеры:

```bat
vbaformat Module1.bas -o Module1.fmt.bas
vbaformat Module1.bas --in-place
for %f in (*.bas) do vbaformat "%f" --in-place
vbaformat Module1.bas --check   rem для пакетной проверки
```

## Что делает

- Отступы по блочной структуре: Sub/Function/Property, If/ElseIf/Else/End If
  (многострочный), For/Next, Do/Loop, While/Wend, With/End With,
  Select Case/Case/End Select, Enum, Type, #If/#Else/#End If, Begin/End
  в шапках форм и классов.
- Однострочный `If ... Then ... [Else ...]` (включая `If a Then: b=1`) отступы не меняет.
- Строки-продолжения ` _` получают +1 уровень от начала логической строки.
- Метки (`ErrHandler:`, номера строк) выносятся на уровень левее тела процедуры.
- Удаляет хвостовые пробелы, схлопывает лишние пустые строки.
- Ключевые слова внутри строковых литералов и комментариев (`'`, `Rem`) игнорируются.
- При несбалансированных блоках — предупреждение в stderr, вывод всё равно формируется.

## Ограничения (осознанные)

- Меняет ТОЛЬКО отступы/пустые строки/хвостовые пробелы: регистр ключевых слов,
  пробелы вокруг операторов, операторы через `:` не трогаются.
- Файл обрабатывается побайтно: кодировка (CP1251/UTF-8), BOM и стиль переводов
  строк (CRLF/LF) сохраняются как во входе. UTF-16 не поддерживается.
- Строка с операторами через `:` классифицируется по первому оператору.

## Тесты

```bat
dmd -unittest -main -run vbaindent.d   rem юнит-тесты движка
cd test && run.bat                     rem 9 эталонных кейсов + идемпотентность
```

`test/big_garbage.bas` — большой «грязный» пример в стиле реального Access-модуля
(не входит в run.bat, для ручной проверки).

## Файлы

- `vbaformat.d` — CLI (разбор аргументов, чтение/запись).
- `vbaindent.d` — движок (классификатор операторов + расчёт отступов + unittests).
- `build.bat`, `test/run.bat`, `test/caseNN_*.{bas,expected}`.
