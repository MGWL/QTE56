## ✅ Проверка качества кода

Когда модель напишет многопоточный код на D, проверь:

### Базовые проверки
- [ ] Импортирован `std.concurrency`?
- [ ] Используется `spawn` для создания потоков?
- [ ] Передается `thisTid` в worker функцию?
- [ ] Используется `send/receive` вместо общих переменных?

### Продвинутые проверки
- [ ] Обработаны все типы сообщений?
- [ ] Используется `receiveTimeout` если нужен?
- [ ] Если `spawnLinked` — обработан `LinkTerminated`?
- [ ] Нет использования `__gshared` для данных?
- [ ] Правильный планировщик выбран?

### Если есть проблемы
- Вставь соответствующий раздел из GUIDE
- Вставь соответствующий пример из EXAMPLES
- Вставь соответствующее исправление из CHEATSHEET

## 🎓 Итоговая чек-лист для продакшена

Перед тем как использовать код написанный AI:

```
Многопоточность:
  [ ] Используется spawn для создания потоков
  [ ] Передается thisTid в worker
  [ ] send/receive для общения
  [ ] Нет __gshared для данных

Обработка сообщений:
  [ ] Все типы сообщений обработаны
  [ ] Есть receiveTimeout если нужен
  [ ] Обработан LinkTerminated для spawnLinked
  [ ] Нет бесконечных receive без выхода

Синхронизация:
  [ ] Нет race conditions
  [ ] Message-passing архитектура
  [ ] Правильный планировщик
  [ ] Регистрация потоков если нужна

Надежность:
  [ ] Обработаны все исключения
  [ ] Нет deadlock'ов
  [ ] Потоки могут завершиться
  [ ] Логирование для отладки
```
