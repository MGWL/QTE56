# 📚 Руководства по памяти D для генеративных моделей

> ↑ Навигация: [AGENTS.md](../../AGENTS.md)

Этот набор файлов поможет AI-моделям (DeepSeek, Claude, GPT, Qwen и др.) генерировать правильный код на D с корректным управлением памятью.

---

## 📁 Файлы в этом наборе

### 1. **D_MEMORY_GUIDE_FOR_AI.md** (основной)
**Размер:** ~400 строк  
**Сложность:** Beginner → Advanced  
**Для чего:** Подробное руководство со всеми концепциями

**Содержит:**
- Основные концепции GC (garbage collector)
- Две памяти: heap (GC) и stack (автоматическая)
- Функции GC: malloc, free, collect, disable/enable, minimize
- Атрибуты памяти (NO_SCAN, NO_MOVE, APPENDABLE, NO_INTERIOR)
- Многопоточность и регистрация памяти
- 5 частых ошибок с исправлениями
- 5 лучших практик
- Справочник для отладки

---

### 2. **D_MEMORY_EXAMPLES.md** (примеры)
**Размер:** ~350 строк  
**Сложность:** Beginner → Advanced  
**Для чего:** Рабочий код, который можно скопировать и адаптировать

**Содержит 7 категорий примеров:**
1. Базовые (массивы, структуры, классы)
2. Продвинутые (malloc с атрибутами, disable/enable GC)
3. Многопоточность (правильные потоки, синхронизация)
4. Ресурсы (RAII, try-finally cleanup)
5. GC проблемы (pause time в real-time коде)
6. Отладка (статистика GC)
7. Опасные ошибки (dangling pointers, скрытые указатели)

## ✅ Проверка качества кода

Когда модель напишет код на D, проверь:

### Базовые проверки
- [ ] Использует `new` вместо `malloc`?
- [ ] Не забыл выделить память (`new`)?
- [ ] Для многопоточности используется `__gshared`?
- [ ] Использует `synchronized` где нужно?

### Продвинутые проверки
- [ ] Не скрывает указатели в int?
- [ ] Не вызывает GC.collect() в цикле?
- [ ] Правильно очищает ресурсы (try-finally)?
- [ ] Использует потоки через `new Thread`?

### Если есть проблемы
- Вставь соответствующий раздел из GUIDE
- Вставь соответствующий пример из EXAMPLES
- Вставь соответствующее исправление из CHEATSHEET

## 🎓 Итоговая чек-лист для продакшена

Перед тем как использовать код написанный AI:

```
Безопасность памяти:
  [ ] Использует new для выделения
  [ ] Правильно обрабатывает cleanup
  [ ] Нет dangling pointers
  [ ] Нет скрытых указателей в int

Многопоточность:
  [ ] Общие переменные помечены __gshared
  [ ] Используется synchronized(mtx)
  [ ] Потоки создаются new Thread()
  [ ] Нет race conditions

Производительность:
  [ ] GC.collect() не в цикле
  [ ] Для real-time используется GC.disable()
  [ ] Нет утечек памяти
  [ ] Статистика GC приемлемая

Надежность:
  [ ] Try-finally для cleanup
  [ ] Правильные деструкторы
  [ ] Правильная обработка ошибок
  [ ] Хорошее логирование
```
