# 📚 Руководства по CSV в D для генеративных моделей

> ↑ Навигация: [AGENTS.md](../../AGENTS.md)

Этот набор файлов поможет AI-моделям (DeepSeek, Claude, GPT, Qwen и др.) генерировать правильный код для работы с CSV на D.

---

## 📁 Файлы в этом наборе

### 1. **CSV_GUIDE_FOR_AI.md** (основной)
**Размер:** ~400 строк  
**Сложность:** Beginner → Advanced  
**Для чего:** Подробное руководство со всеми концепциями

**Содержит:**
- Основные концепции CSV и RFC-4180
- Главная функция csvReader
- Функция низкоуровневого разбора csvNextToken
- Типы исключений (CSVException, IncompleteCellException, HeaderMismatchException)
- Обработка ошибок (Malformed enum)
- Типы содержимого (string, числа, Tuple, struct, class, ассоциативный массив)
- Работа с заголовками
- Кастомные разделители
- 5 частых ошибок с исправлениями
- 5 лучших практик

## ✅ Проверка качества кода

Когда модель напишет код с CSV на D, проверь:

### Базовые проверки
- [ ] Импортирован `std.csv`?
- [ ] Использует `csvReader` вместо самодельного парсера?
- [ ] Правильный разделитель (`,` или другой)?
- [ ] Структура совпадает с порядком в CSV?

### Продвинутые проверки
- [ ] Обработаны `CSVException`?
- [ ] Правильно используется заголовок (null или массив)?
- [ ] Для больших файлов используется `byLine.joiner`?
- [ ] Разное число полей → `true` параметр?
- [ ] Используется `Malformed.ignore` для слабого CSV?

### Если есть проблемы
- Вставь соответствующий раздел из GUIDE
- Вставь соответствующий пример из EXAMPLES
- Вставь соответствующее исправление из CHEATSHEET
