# Правила для AI-агентов (QTE56 DMC)

> ↑ Навигация: [AGENTS.md](../AGENTS.md)

## Запрет на EnterPlanMode

**ВАЖНОЕ ПРАВИЛО:** Не вызывай инструмент `EnterPlanMode` без прямого указания пользователя.

- Если пользователь не сказал явно "войди в плановый режим", "составь план" или подобное — **не используй `EnterPlanMode`**.
- Для простых задач (запуск скриптов, мелкие правки, однострочные изменения) — действуй сразу, без планирования.
- `EnterPlanMode` допустим только когда пользователь явно попросил спланировать задачу.

## Рабочий процесс

1. Пользователь просит задачу
2. Если задача **тривиальная** (один файл, простое изменение, запуск скрипта) → **действуй сразу**, без `EnterPlanMode`
3. Если задача **сложная** и пользователь **явно попросил** составить план → используй `EnterPlanMode`
4. После утверждения плана → просто выполняй, **не включай `EnterPlanMode` повторно**

## Примеры тривиальных задач (без EnterPlanMode)

- Запустить существующий скрипт
- Исправить опечатку в одном файле
- Изменить путь/параметр в конфиге
- Добавить одну функцию/метод
- Обновить вывод скрипта
- Прочитать и показать содержимое файла

## Примеры сложных задач (с EnterPlanMode только по запросу)

- Рефакторинг архитектуры
- Добавление нового модуля/подсистемы
- Изменение интерфейсов, затрагивающих множество файлов
- Реализация новой функциональности с нуля

## Примечание

Это правило имеет **наивысший приоритет** и отменяет любые общие инструкции о необходимости планирования.
